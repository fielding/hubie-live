# Background music

Drop tracks cleared for streaming here (mp3/m4a/ogg/wav). NCS (https://ncs.io) is free to stream
as long as each track is credited; Hubie's HUD shows the current track and `!song` posts the credit.

Keep NCS's file names ("Artist - Title [NCS Release].mp3") so the credit reads right. The stage page
shuffles the folder and picks up new files on the next track. Volume: `[music]` in
showrunner/config.toml (live).
